# research/

Purpose: replace guesses with evidence — users, market, technology.

| Skill | Load when |
|---|---|
| `research` | Factual question; primary sources; capture note in repo/vault. |
| `user-research` | Interviews, surveys, transcripts, support tickets, ICP synthesis. |
| `market-research` | Market sizing, competitor comparison, technology scans, cited. |
| `technical-spike` | Feasibility question with a time box and exit criteria. |

Combos: discovery → `user-research` → `product/grilling` → `product/to-spec`. Unknown tech risk → `technical-spike` → `design/prototype`.
