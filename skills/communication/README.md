# communication/

Purpose: make decisions and status legible to people who were not in the session.

| Skill | Load when |
|---|---|
| `internal-comms` | Status report, leadership update, 3P update, FAQ, incident comms. |
| `handoff` | Compact this conversation for the next agent/session. |
| `to-questionnaire` | A decision is someone else's — turn it into a form they can fill in. |
| `linear-problem-report` | A Linear issue was pasted in and the user wants it explained back as a problem, not restated. |

Combos: weekly update → `documentation/vault-knowledge-retrieval` → `internal-comms`. Daily automated status → `operations/daily-app-status`.
