# documentation/

Purpose: keep the vault (`Second Brain/`) true to the code, and produce visuals that decide things.

| Skill | Load when |
|---|---|
| `vault-knowledge-retrieval` | Any question about what the product does / how a module works / what an id means. Read before exploring code. |
| `vault-note-creation` | New PRD/API/DATAFLOW/BPMN, tech plan, postmortem, handoff — per AGENTS.md §2/§3. |
| `vault-note-update` | A fact changed; propagate everywhere it is stated; ids stable. |
| `html-canvas` | CEO/MM brief, proposal page, options comparison in app design system. |
| `architecture-diagram` | Dark-themed system/infra HTML+SVG diagram. |
| `bpmn` | Business process diagram (PlantUML/BPMN) → `BPMN/BPMN.mermaid` slot. |

Combos: every build ends `vault-note-update` (AGENTS.md §4). ADRs → `product/domain-modeling`. API docs → `engineering/api-design` + `API/API.md` slot.
